# Quickstart: Hermetic Replay Build Qualification

1. Build a predeclared ordered sample with per-revision legal records, a recipe reference, and immutable runner descriptor.
2. Prepare it and retain the preparation hash.
3. Run it through an authorized injected runner.
4. Reduce all rows against the frozen floor; reject incomplete or clustered results.
5. Verify with focused qualification tests before using any output as build evidence.
