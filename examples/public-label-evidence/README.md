# Public label-semantics evidence fixture

`manifest.json` is intentionally blocked: this repository does not bundle a
public dataset snapshot or silently fetch one. A future supplied fixture must
record the published source/version, license, retrieval reference, checksum,
structured label definition, aligned-event scope, and evaluation procedure.

This lane can establish only public-label evidence. It cannot establish label
interchangeability, Semantic/Full Conformance, or predictive efficacy.
